# Генератор случайных цитат (Random Quote Generator)

## Автор
**Евгений Банников** 

## Описание
GUI-приложение «Генератор случайных цитат», разработанное на Python. Приложение позволяет генерировать случайные цитаты, сохранять историю просмотров, фильтровать цитаты по автору и теме, а также добавлять собственные цитаты.

### Основные возможности:
- **15 предопределённых цитат** на русском языке с текстом, автором и темой
- **Генерация случайных цитат** одним нажатием кнопки
- **История просмотров** с отображением в виде прокручиваемого списка
- **Фильтрация истории** по автору и теме
- **Сохранение и загрузка истории** в JSON-файл (quotes_history.json)
- **Добавление собственных цитат** с проверкой на пустые поля
- **Валидация ввода** — защита от добавления цитат с пустыми полями

## Описание
Генератор случайных цитат — это настольное приложение с графическим интерфейсом, созданное на Python. Приложение позволяет пользователям:

- Генерировать случайные цитаты из предопределенной коллекции
- Просматривать историю всех сгенерированных цитат
- Фильтровать историю по автору или теме
- Добавлять новые пользовательские цитаты в коллекцию
- Автоматически сохранять и загружать историю из JSON-файла

### Функции
1. **Генерация цитат**: Нажмите «Сгенерировать цитату», чтобы отобразить случайную цитату с текстом, автором и темой
2. **Отслеживание истории**: Все сгенерированные цитаты сохраняются в прокручиваемом списке истории
3. **Фильтрация**: Фильтруйте историю по имени автора или категории темы
4. **Пользовательские цитаты**: Добавляйте свои собственные цитаты с проверкой пустых полей
5. **Сохранение**: История автоматически сохраняется в файле quotes_history.json и загружается при запуске

## Примеры использования

### Основное использование
1. Запустите приложение
2. Нажмите «🎲 Сгенерировать цитату», чтобы увидеть случайную цитату
3. Просмотрите сгенерированные цитаты на панели истории

### Фильтрация
1. Введите имя автора (например, «Стив Джобс») в поле «Автор»
2. Введите тему (например, «Мотивация») в поле «Тема»
3. Нажмите «Применить фильтр», чтобы увидеть подходящие цитаты
4. Нажмите «Сбросить», чтобы показать всю историю

### Добавление пользовательских цитат
1. Нажмите «➕ Добавить новую цитату»
2. Заполните текст цитаты, имя автора и тему
3. Нажмите «Сохранить» (проверка предотвращает заполнение пустых полей)

## Тестирование

4. Закройте и снова откройте приложение, чтобы проверить сохранение истории.

## Примеры использования

### Генерация цитаты
1. Запустите приложение
2. Нажмите кнопку **«🎲 Сгенерировать цитату»**
3. Цитата отобразится в верхней части окна и будет добавлена в историю

### Фильтрация истории
1. Введите имя автора или тему в соответствующие поля
2. Нажмите кнопку **«Применить фильтр»**
3. Для сброса фильтра нажмите кнопку **«Сбросить»**

### Добавление новой цитаты
1. Нажмите кнопку **«➕ Добавить цитату»**
2. Заполните все поля (текст цитаты, автор, тема)
3. Нажмите **«Сохранить»**
4. Пустые поля не будут приняты — появится сообщение об ошибке

### Очистка истории
1. Нажмите кнопку **«🗑️ Очистить историю»**
2. Подтвердите действие в диалоговом окне
